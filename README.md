# mcquenji's Homebrew tap

Install Tug on macOS or Linux:

```sh
brew install mcquenji/tap/tug
```

Update an existing installation:

```sh
brew update
brew upgrade mcquenji/tap/tug
```

The formula is published by [Tug's tagged-release workflow](https://github.com/mcquenji/tug/actions/workflows/release.yml) after all native builds succeed. It will appear after the first release completes. Formula changes contain versioned GitHub Release URLs and SHA-256 checksums.

See [Tug](https://github.com/mcquenji/tug) for configuration and [release documentation](https://github.com/mcquenji/tug/blob/main/docs/releases.md) for supported platforms and publishing instructions. Windows binaries are available from [Tug releases](https://github.com/mcquenji/tug/releases).
